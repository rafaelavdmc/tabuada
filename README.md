# Tabuada em C
Este projeto é um programa desenvolvido em C que recebe um número inteiro e exibe a sua tabuada de multiplicação de 1 a 10.
##  Requisitos
É necessário ter o compilador **GCC** instalado.
##  Como Compilar e Executar
1. **Compilar o programa:**
gcc main.c -o tabuada
2. **Executar no Linux:**
bash ./tabuada
3. **Executar no Windows:**
tabuada.exe
## Exemplo de Uso
**Entrada:**
`2`
**Saída:**
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
2 x 10 = 20
